# AISB-AUTOSPAWN — Master AISB auto-spawned on every launch

**Category:** Orchestration
**Added:** 2026-05-27

## Rule

When omega menu starts, the AISB Master session is auto-created if missing. Pinned at top, system prompt via --append-system-prompt-file (invisible), conversation resumed via --continue.

## Origin

The user wants a persistent always-on chat with AISB.
