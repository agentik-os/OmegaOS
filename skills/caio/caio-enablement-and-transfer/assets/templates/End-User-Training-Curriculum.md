## Per-audience tailoring
- **Skeptics:** M1 first and slow (defuse the fear, show HITL control); a private M3 (no audience) so the first failure isn't public.
- **Neutrals:** compress M1; get to M3 fast; quantify time returned.
- **Champions:** fast-track M1-M3; add a teach-the-trainer module so they can run M2-M3 for peers.
