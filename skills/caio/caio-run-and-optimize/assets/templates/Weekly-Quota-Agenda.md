## The overage boundary (mm-08 — margin discipline · Iron Law 8)

| Request | Inside the hour? | Routing |
|---|---|---|
| Strategic question / arbitration | YES | logged here |
| New-integration *scoping* | YES | logged here |
| New workflow / migration / department expansion | NO | scoped SOW → `/market-proposal` |
| Operational firefighting / manual ops | NO | client's system owner (or a scoped fix) |

> Unbounded consulting time is the margin bomb of mm-08 applied to services. Anything bigger than the hour is scoped and priced, never silently absorbed. Saying "that's a scoped piece" keeps the 1h/week format honest.
