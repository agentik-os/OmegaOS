# 180-Day Identity Transformation Protocol

## Phase 0: Baseline (Days -3 to 0)

Capture reality without judgment:
- health
- body
- finances
- work
- relationships
- environment
- habits
- attention
- unfinished commitments
- current identity language

Deliverable: Baseline dossier + Identity Contract.

## Phase 1: Stabilize (Days 1-30)

Objective: stop identity leakage.

Focus:
- sleep
- sobriety / harmful habit removal
- environment cleanup
- minimum viable routines
- client/work reliability
- one daily build block
- daily journal

Success marker: user can keep promises to self consistently.

## Phase 2: Align (Days 31-60)

Objective: make calendar and behavior match declared priorities.

Focus:
- time allocation
- deep work
- nutrition/training consistency
- relationship hygiene
- friction removal
- unnecessary commitment elimination

Success marker: fewer contradictions between stated priorities and observed behavior.

## Phase 3: Expand (Days 61-90)

Objective: increase capability and exposure.

Focus:
- harder professional asks
- stronger physical progression
- social challenges
- new environments
- public proof where useful
- shipping meaningful work

Success marker: measurable external outcomes begin compounding.

## Phase 4: Embody (Days 91-120)

Objective: make the new identity visible in default behavior.

Focus:
- consistency under stress
- stronger standards
- style / presence / communication
- leadership
- difficult conversations
- reputation

Success marker: user requires less conscious effort to behave in alignment.

## Phase 5: Leverage (Days 121-150)

Objective: turn identity into leverage.

Focus:
- systems
- delegation
- network
- audience/content if relevant
- capital
- partnerships
- reusable knowledge

Success marker: outcomes increasingly come from systems and relationships rather than raw effort.

## Phase 6: Consolidate (Days 151-180)

Objective: make regression unlikely.

Focus:
- evidence review
- relapse map
- maintenance rules
- next 12-month vision
- keep/remove/upgrade decisions
- identity proof narrative

Success marker: user has a functioning operating system, not a temporary challenge.
