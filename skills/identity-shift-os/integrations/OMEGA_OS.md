# Omega OS Integration Contract

## Role
Identity Shift {OS} is a strategic orchestration layer.

It decides:
- what matters now
- what is misaligned
- which specialist should be invoked
- what evidence should be recorded

It does not replace specialists.

## Handoff examples

Identity problem -> Mindset OS
Habit problem -> Habit Tracker OS
Execution problem -> Execution OS
Idea problem -> Brainstorm OS
Validation problem -> Market Research OS
Product definition -> Blueprint OS
UX -> Design OS
Implementation sequencing -> Stepper OS
Implementation -> Builder OS
Story communication -> Storyteller OS
CAIO delivery -> CAIO systems

## Handoff packet

Every handoff should include:
- user objective
- current context
- constraints
- relevant evidence
- expected outcome
- success condition
- deadline if any

## Return packet

Specialist OS returns:
- actions
- decisions
- artifacts
- risks
- evidence
- next trigger

Identity Shift incorporates the result into the user's longitudinal state.
