# Start Identity Shift

Run a baseline interview and produce:

1. Current reality
2. Desired future identity
3. 180-day outcomes
4. Values
5. Standards
6. Anti-identity
7. Non-negotiables
8. Key metrics
9. Known risks
10. First 30-day phase
11. Day 1 protocol

Ask only questions that materially change the plan.
Do not create an enormous intake questionnaire if the information is already known.
