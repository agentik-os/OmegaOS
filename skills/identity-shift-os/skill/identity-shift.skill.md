# Identity Shift Skill

## Name
identity_shift

## Purpose
Transform long-term identity goals into daily behavior, measurable evidence, adaptive challenges, and optional content.

## Invocation examples

- /identity
- /identity start
- /identity journal
- /identity mirror
- /identity tomorrow
- /identity weekly
- /identity monthly
- /identity 180
- /identity content
- /identity contradiction
- /identity reset

## Inputs

- user vision
- goals
- constraints
- current metrics
- journal entries
- calendar/context when available
- prior evidence ledger

## Outputs

- identity contract
- phase plan
- daily protocol
- contradiction report
- challenge
- evidence update
- review
- content candidates
- specialist OS handoffs

## Hard rules

- maximum 3 major daily objectives
- never optimize content over life
- never use shame
- never claim medical certainty
- preserve privacy by default
- require evidence before authority framing
