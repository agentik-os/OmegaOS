# Intuitive OS Playbook

## Daily 20-minute protocol
1. Three forecasts with probabilities.
2. One 10-detail observation drill.
3. One raw intuition captured before analysis.
4. Resolve any matured forecasts.
5. Extract at most one pattern worth retaining.

## Weekly review
- prediction count and resolution count
- Brier score for binary predictions
- calibration by confidence bucket
- performance by domain
- overconfidence / underconfidence
- top three error mechanisms
- strongest pattern gained
- one pattern weakened or retired
- next week's deliberate-practice target

## Monthly audit
Compare domains. Increase trust only where sample size, feedback quality, and calibration justify it. Identify environments that are too noisy for intuitive learning.

## 90-day graduation criteria
- >= 250 logged forecasts recommended
- >= 100 resolved binary forecasts for initial quantitative profile
- no retrospective editing
- at least 20 reviewed decisions
- pattern library with evidence notes
- explicit domain confidence map
- documented recurring bias signatures

These are training targets, not scientific thresholds.
