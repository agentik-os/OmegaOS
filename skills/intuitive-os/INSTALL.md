# Install into Omega / Agentik OS

1. Copy this folder into your OS skills/modules directory.
2. Register `SKILL.md` as the skill entrypoint.
3. Load `prompt/INTUITIVE_OS_SYSTEM.md` when `/intuition` routes.
4. Persist prediction, decision, and pattern records in your preferred store.
5. Run `python -m pytest tests` if Python is available.
6. Start with `/intuition setup`, then `/intuition 90d`.
