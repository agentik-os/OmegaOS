# Tier-1 Inspiration — The Canonical Sites-Inspirants

The reference set every OmegaOS design skill builds to **by default**. These 19 sites are the bar: an adversarially-verified ledger of what makes Linear-tier web design read as crafted instead of generic. When a brief says "make it clean / premium / modern" with no other direction, build to **this** — not to a Tailwind-template default.

**Anchor = `linear.app`.** Every other entry is measured against it on five axes: Typography, Motion, Spacing, Color, Micro-interactions. Specifics below are corrected against live DOM / shipped CSS where verifiable; where a value was only third-party-inferred or the site was unreachable, it is phrased as "reads as" rather than asserted as a false fact. Copy the *discipline*, not the hex blindly.

---

## The Anchor: `linear.app`

THE bar. The whole point of restraint-as-craft. Austere where its imitators are loud — the real site is *more* minimal than "Linear-style" clones, which overuse a purple glow Linear itself doesn't ship.

- **Typography** — Live DOM resolves to **Inter Variable** (body/UI) + a **Berkeley/JetBrains-class mono** (IDs, diffs, metadata). The proprietary "Linear Display/Text/Mono" names appear only in third-party reverse-engineering; the official brand page lists no typeface at all. Set display in **Inter at weight 600 max** (never 700+; card titles 500, subheads 400 — headlines whisper). Signature move: **size-proportional NEGATIVE tracking** — roughly `-0.035em` at 56px+, `-0.025em` at 40px, `~-0.013em` (-0.62px) at 48px, easing to `-0.005em` at 16px body. Body never drops below ~13–14px. The 13px uppercase eyebrow is the **only** positive-tracking context (`+0.4px`). [Third-party measured: the 64/40/32/24/20/18 scale and the per-size tracking table are community values, not from official CSS.]
- **Motion** — The signature is **restraint, not a curve.** Product-UI mockups animate *subtly in place* (zoom/fade), never flying in. High-frequency nav hover is **0ms / instant** (per Linear's own May-2026 changelog), not an eased fade. Reserve short animated transitions for infrequent overlay entrances. Exact durations/curves are NOT readable from the DOM — the popular "sub-200ms cubic-bezier" band is an inference; treat ~120–180ms as a *starting target*, not a canonical number. The motion philosophy ("You Don't Need Animations", "never animate keyboard actions") actively *suppresses* motion on the most-used surfaces.
- **Spacing** — 4px ladder: `4 / 8 / 12 / 16 / 24 / 32 / 48`, with a dedicated **96px section token** for vertical rhythm. Content capped at **1280px**. CTAs tight at `8px / 14px` padding. Build each section to **frame a product screenshot**, not fill space with prose — Linear gives the majority of each section's area to a mockup.
- **Color** — Near-black canvas (live-DOM `#08090A`, never pure `#000`), off-white ink `#f7f8f8` stepping down a cool gray ramp `#d0d6e0 → #8a8f98 → #62666d`. The homepage is a **dark hero + content with a light/neutral nav** (mixed-mode, not uniformly dark-first). Exactly **ONE accent**: a desaturated indigo widely catalogued as `#5e6ad2` (hover `#828fff`) — but the brand page only says "a subtle desaturated blue" with no hex, so treat the figure as *community-measured*. No second accent hue anywhere.
- **Micro-interactions** — **Depth = surface ladder + hairlines, NOT shadows.** Build cards from a four-step near-black ladder (`#0f1011 / #141516 / #18191a / #191a1b`) separated by **1px hairline borders** (`#23252a`); ban drop-shadows. On focus, strengthen the border to `#34343a` or draw a 2px outline at ~50% opacity — never a glow. Radius ladder: 4px chips / 8px buttons / 12px feature cards / 16px screenshots / 9999px pills only. [Surface-ladder + hairline hexes are from a reverse-eng spec, not official tokens — plausible, not independently CSS-confirmed.]

> **Signature in one line:** depth without shadows (a ladder of near-identical near-blacks split by 1px hairlines) + size-proportional negative tracking on Inter display, on a cool near-black canvas with a single desaturated indigo.

## Tier 1 — Quasi-identical to Linear

`vercel.com` · `planetscale.com` · `railway.app` · `resend.com` · `cal.com`

### `vercel.com` — the developer-platform dialect (arguably co-author of the aesthetic)
- **Typography** — Ships its **own** typeface: **Geist Sans** (UI/display) + **Geist Mono** (code, metrics, terminal labels) — a geometric Swiss grotesk, high x-height, angular terminals. (A third face, **Geist Pixel**, now exists as display novelty.) Tighten tracking as size grows: `-0.04em` on 48–64px display at ~1.15 line-height, `-0.01em` on body; never below 14px. Mono-as-visible-texture is the Vercel tell.
- **Motion** — **Vercel publishes NO motion tokens.** The observable signature: the shared-layout nav — one translucent highlight pill that physically *slides* between items while the dropdown panel *resizes* to each menu's content (a continuous shared element, not show/hide). Implementation is community-attributed to Framer Motion `layoutId` but **unverified** — treat as behavioral observation. Do NOT copy `cubic-bezier(0.4,0,0.2,1)` and call it "Vercel": that is Material Design's standard easing. Reconstruct real timing from DevTools on the live site.
- **Spacing** — 8px grid `4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96 / 128`, large 48–128px section padding, content self-contained in **hairline-boxed card blocks** with big dark gutters (isolation by 1px `rgba(255,255,255,0.08)` cards, not just a max-width container).
- **Color** — Pure-monochrome dark-first. Canvas `#000000`, default text **`#EDEDED`** (not pure white — `color-text-default`, per designsystems.one), one true-neutral gray ramp with **zero tint** (`#F7F7F7 → #0A0A0A`). The ONLY chroma is Vercel blue **`#0070F3`** as punctuation (links / primary buttons / active+focus), never decorative. Status reds/ambers functional only.
- **Micro-interactions** — Hairline 1px borders at `rgba(255,255,255,0.08)` stepping to `~0.15` on hover/emphasis — surfaces "firm up" instead of recoloring. Favor opacity/position deltas over color floods; the page stays monochrome and lets motion + the single blue signal everything.
- **Relation to `linear.app`** — Tier-1 sibling, beat-for-beat: dark-first, pure-neutral palette, single cool accent, hairline borders, sub-200ms eased chrome. Diverges by shipping **Geist** (own type), leaning harder on visible mono, a warmer developer-blue used even more sparingly, and making the **morphing shared-layout nav** its craft tell where Linear's lives in product-surface depth.
- **Signature:** the morphing shared-layout nav — a single highlight pill that slides while the panel resizes to each menu's content.

### `planetscale.com` — the terminal/README dialect
- **Typography** — **Ships ZERO custom fonts.** Body defaults to **monospace** (`ui-monospace, SFMono-Regular, SF Mono, Menlo, Consolas, …`); prose opts *back* into sans via a `.sans-prose` class — monospace is the base, sans is the exception. The mono stack is load-bearing: it renders ASCII Vitess sharding diagrams (`╔═╗ └─┘ ┴ │ ─`, `░`-shaded blocks), pipe `|` nav separators, `▾` carets. Headings `font-semibold` (600), never black. Per-size tracking (`h1 -.019em`, `h2 -.017em`, `text-lg -.014em`) plus `tracking-tight -.025em` / `tracking-widest .1em` on uppercase labels.
- **Motion** — The real signature is **near-total absence of transition on hover.** Nav/link hover color swaps are **0ms instant step-cuts** (no `.transition` class); the `▾` caret rotates as a step-flip, not an animated turn. Only the orange hero CTA (`.cta a:first-child`) animates, at 150ms. (No `prefers-reduced-motion` anywhere — a real a11y gap; don't copy that part.)
- **Spacing** — Tailwind `.container` (max 1280px on `max-w-7xl`), dense and document-like (`mb-6 mt-4`, `gap-y-3 / gap-1.5`) — it spaces like a technical spec sheet, not a billboard.
- **Color** — Dark-capable via `prefers-color-scheme` (theme-color `#111111`), strictly **neutral untinted gray** (R=G=B: `#fafafa … #111111`). ONE **warm** accent: **PlanetScale Orange `#f35815`** (orange-500) — the deliberate inverse of Linear's cool blue; only filled CTA + only `hover:text-orange`. Keeps a fuller functional palette (blues/greens/reds/yellows) for tags/diagrams/syntax.
- **Micro-interactions** — Sharp corners by **absence of rounding** (`.btn` declares no `border-radius`; no global reset) — boxy, document geometry. `box-shadow:none` dominates; structure carried by the **dashed-box** (stacked `repeating-linear-gradient`s, 12px dash / 4px gap) and `░`-shaded ASCII, not by shadows.
- **Relation to `linear.app`** — Same neutral-palette/single-accent/disciplined spine, but diverges hard on surface: no custom font (system sans+mono), WARM orange, sharp 0-radius boxes, dashed line-work + ASCII instead of glow — a deliberately rawer, plaintext "technical README" skin (reportedly drafted in Google Docs).
- **Signature:** the dashed-box border system + monospace ASCII system diagrams — line-work and terminal cues carry the engineering credibility, never gradients.

### `railway.app` — the warm, theatrical dialect
- **Typography** — **Three families.** DISPLAY = **IBM Plex Serif** (`font-medium`/500) — a serif headline is the single biggest fingerprint vs Linear's grotesk. UI/BODY = **Inter** (`text-sm` for dense UI, `text-base` for prose). MONO = **JetBrains Mono** (code + the split-flap board). Size-scaled negative tracking: `-1.96px` at 54px hero, `-0.72/-0.8px` at 36–40px section titles. Exception: the split-flap "now boarding" heading uses **Inter Tight** semibold — Plex Serif covers 8 of 9 display heads; reserve Inter Tight for ticker/numeric contexts.
- **Motion** — Interactive feedback is `transition-[background-size,box-shadow] duration-[250ms] ease-in-out` (CTA glow expansion) — NOT a custom cubic-bezier. The bezier curves (`cubic-bezier(0.215,0.610,0.355,1.000)` easeOutCubic, `cubic-bezier(0.190,1.000,0.220,1.000)` easeOutExpo) are reserved for **ambient/entrance** at 700ms–1s (blob reveals, train SVGs). Accordion chevrons use `ease-in`. Trains are **group-hover-triggered**, not ambient; the tweet marquee is ambient but pauses on hover.
- **Spacing** — `py-16` (64px) standard section beat, `py-24`/`py-20` for majors; tight `gap-4`. Whitespace framed by a faint **1px `bg-white/20` blueprint-grid** on responsive thirds/sixths (`left-[16.6667%]` … `hidden lg:block`) rather than bordered cards.
- **Color** — **VIOLET-tinted** dark base `hsl(250,24%,9%)` (#13111c family) — the ENTIRE gray ramp runs at hue 246 (every "gray" carries a purple cast). Accent is **magenta→violet**, not blue: focus ring `ring-pink-700` (general) / `ring-pink-600` (CTA only); CTA gradient `#aa0aaa → #6d1dbd → #381dbd` wrapped in dual glow shadows. Light mode is a real, separate cream palette (`#f1f0ef` oatmeal) — don't implement only the dark path.
- **Micro-interactions** — CTA hover **grows the glow, not the box** (`bg-[length:100%_200%]`, shadow spread→32px, opacity→.50); press = `active:scale-95` + darken stops. Borders nearly absent (2 decls on the page); depth via translucent `bg-white/5..20` glass fills + grid hairlines. `focus-visible:ring-2 ring-pink-700`.
- **Relation to `linear.app`** — Extends the engineering grammar onto a warmer, more theatrical brand: serif display, magenta→violet accent, violet-tinted neutrals, glass fills over hairlines, plus playful motion (split-flap board, crossing trains, day↔dusk hero) Linear would never ship. Same craftsmanship bar, opposite temperament.
- **Signature:** the live SPLIT-FLAP departure board (JetBrains Mono, `--flap-width:32px`) flipping five live metrics — the "Railway" station metaphor rendered as motion.

### `resend.com` — Linear restraint, "animated light" replacing the one accent
- **Typography** — Display H1 is **Domaine Display** (Klim) on the homepage (`text-[4rem] md:text-[6rem] tracking-[-0.01em]`); **ABC Favorit** (Dinamo) handles H2 subheads (`tracking-tighter` -.05em); **Inter** body; **Commit Mono** code; **Univers** for app-layer UI. (Earlier "ABC-Favorit-is-the-hero" framing is wrong — Domaine carries the flagship head; the `clamp(4rem,10.26vw,7.5rem)` util exists but is unused on the homepage.)
- **Motion** — Dual baseline **150ms + 200ms** (200ms is the more frequent *applied* duration) on the `ease-in-out` keyword. The flashy spring/editorial curves exist in the bundle but are **latent (unused on the homepage)** — don't present them as live. Real homepage motion signatures: **disco-border** (6s rotating conic-gradient halo on active tabs), **plop** (3-dot staggered pulse), **texture-btn** (noise-PNG revealed on CTA hover), **scroll-shadow-line** (`animation-timeline:scroll(self)`).
- **Spacing** — Tailwind scale; full-bleed bands separated by hairline dividers (not boxed cards). Fluid `clamp()` sizing is a signature; density is low — one focal element (terminal/code block, email-preview mock) per band.
- **Color** — Achromatic-first: background `#000000`/`#030303`, text on a Radix gray ramp (`--gray-1…--gray-12`, body = `gray-12`). There is **NO solid UI accent.** Chromatic color lives only inside animated gradients — and on the homepage the divider gradient is a **gray shimmer** (`rgba(56,189,248,0)` cyan and `rgba(236,72,153,0)` pink endpoints are *transparent*; the visible band is `~rgba(143,143,143,0.67)` at the midpoint). Named `--rainbow-cyan/-amber/-purple` tokens exist but the surface reads black-and-white with a traveling glow.
- **Micro-interactions** — True hairlines (1px + sub-pixel .5px). Depth from 1px lines + gradient-box fills (`background:border-box linear-gradient(…)`, `conic-gradient(from 90deg)`) — but Resend *does* use `box-shadow` here (a thick `0 0 0 8px rgba(0,0,0,1)` ring framing code surfaces; multi-layer inset shadows for glass cards). Inline code uses **Prism.js** token spans (`token.punctuation/.keyword/.string/.plain`) so snippets read IDE-highlighted.
- **Relation to `linear.app`** — Shares the core grammar (near-pure-black, Radix-gray restraint, tight tracking, hairlines, developer tone) but **refuses a solid accent entirely** — Linear's "one accent" is replaced by "animated light on grayscale." Warmer display face (Domaine + ABC Favorit) than Linear's grotesk.
- **Signature:** the animated divider hairline — a grayscale 1px rule with a soft glow band traveling across it (cyan/pink endpoints transparent), letting an achromatic page feel alive.

### `cal.com` — Linear chassis, monochrome-as-brand instead of a hue
- **Typography** — DISPLAY = **Cal Sans** (cal.com's own open-source geometric sans, three families Cal Sans UI/Text/Geo, 5 weights, single-story `a`/UI `G`/Futura alts) at 20–28px headings; BODY/UI = **Inter** at 14–16px. The inverse of Linear's negative tracking: the docs **mandate POSITIVE letter-spacing** on small Cal Sans subheads so they don't bunch; large heads ship at default tracking. Weight doctrine: large single-line semibold only, large multiline medium only.
- **Motion** — The one bespoke curve is `cubic-bezier(.21, 1.02, .73, 1)` (mild overshoot, y>1) on a 600ms fade-in-up entrance — everything else is **Tailwind/Radix defaults** (`cubic-bezier(0.4,0,0.2,1)` at 150ms — which is Tailwind's `ease-in-out`, not ease-out). No framer-motion/spring engine (high confidence). Radix primitives fire at their own defaults; cal.com overrides zero Radix animation tokens.
- **Spacing** — Canonical control radius is **4px** (`--radius-cal: .25rem`), 8px for larger controls, 1px hairline borders. (A separate `coss-ui` shadcn package uses a 10px base — don't conflate the two.) Sections use a numbered-day-block calendar motif; the actionable steal is the **animated-number-within-cell** interaction, not a spacing algorithm.
- **Color** — VERIFIED grayscale-**by-doctrine** ("a grayscale brand to emphasise boldness and professionalism", inspiration drawn from Uber). The "accent" is a **theme-flipping neutral**, not a hue: near-black `#111827` on white text (light) / pure `#fff` on black text (dark) — a solid black-or-white CTA block. Surfaces `#fff / #eef0f3 / #f6f7f9 / #e5e7eb`. Saturation reserved for state only (success `#17a76f`, attention `#ffe7c2`, info `#0d1473`). The one saturated color belongs to the **end-user's booking page**, not to cal.com itself.
- **Micro-interactions** — Custom `::selection { color: brand-text; background: brand }` paints selected text in the grayscale brand pair. Buttons gain depth via graded shadow tokens per state (`--shadow-button-solid-brand-{default,hover,active,focused}`) + a 0.5px `active:translate-y` press (subtle), not color jumps. Focus = the Radix blue ring `rgb(59 130 246 / 0.5)`.
- **Relation to `linear.app`** — Same dark-first chassis, crisp grotesk + neutral sans, hairlines, tight radii, depth-via-shadow over decoration. Diverges on the two identity axes: **refuses a hue** (Uber-style theme-inverting near-black/white) and runs a **warmer typeface that wants positive tracking** at small sizes.
- **Signature:** the grayscale-as-brand discipline — one neutral "accent" that flips black↔white with the theme, every color budget spent on type and the calendar grid.

## Tier 2 — Same energy

`clerk.com` · `trigger.dev` · `turso.tech` · `outstatic.com` · `supabase.com` · `neon.tech`

### `clerk.com` — light-first, warm violet primary + cyan glow
- **Typography** — **Suisse Int'l** (Swiss neo-grotesk, self-hosted, 5 static cuts incl. a dedicated Book/450) as brand face; **Söhne Mono** for code; a variable Geist face for tabular numbers. Body floor **15px** (`--text-base .9375rem`), NEVER 16px. Display 48–80px with tracking `-.025em` to `-.035em`; uppercase eyebrows `+.04em`–`+.1em`. (Suisse is NOT variable — 510/590 are CSS utility values the browser rounds, not optical axes.)
- **Motion** — Dominant easing is `cubic-bezier(.33,1,.68,1)` (smooth decelerate-then-linger), NOT the Material pair. Springiness comes via CSS `linear()` polyfilling Tailwind `spring()` + Framer Motion (`stiffness:100, damping:10, bounce:0.3`). Three tiers: 75–200ms micro-feedback / 300–500ms reveals / 700ms–1s hero. Site-specific extras: `active:scale-[0.98]` button press, `corner-shape:squircle`, a `letter-reveal` blur-in on hero text.
- **Spacing** — 4px radius grid (`2/4/6/8/12/16px`), main column `min(75.75rem, …)` ≈ **1212px**, prose narrowed to 36–48rem. Tall section rhythm; modern oklab/lab color math.
- **Color** — **LIGHT-MODE-FIRST** with a `--light/--dark` token swap (NOT `prefers-color-scheme`). Extended neutral ramp with half-steps (`gray-25 #fafafb … gray-950 #131316`). Primary action = **warm violet `#6c47ff`** on every CTA. ONE cool accent **`#5de3ff`** (sky-300) demoted to icons/selected/strokes/glow — the inverse of Linear's cool-everything.
- **Micro-interactions** — Hairlines at **both .5px and 1px**. Depth = layered shadows whose FIRST layer is a `0 0 0 .5px` rim + an `inset 0 0 0 .5px` rim (not a soft drop). Focus = 2-ring glow (`0 0 0 1px` + `0 0 0 4px`). The signature halo is a **four-stop** gradient (`#5de3ff59 7% → #369df24d 22% → #654bf626 64% → transparent`) — a warm-to-cool shift, not a flat cyan wash.
- **Relation to `linear.app`** — Same craft vocabulary almost beat-for-beat (Swiss grotesk, tight tracking, .5px/1px hairlines, inset-rim shadows, single-accent-as-glow, 4px grid, multi-ring focus) but **light-mode-first** with a **warm violet primary**, demoting the Linear-style cool cyan to an accent role.
- **Signature:** dark cards floated over a light page, lit by a top-anchored four-stop cyan→violet halo; warm violet owns every action.

### `trigger.dev` — acid-lime on bespoke charcoal
- **Typography** — **Satoshi Variable** (300–900) is the **title/display** face only (`.font-title`); **Geist Variable** is the actual **UI/body** font (`.font-sans`, the html base); **Geist Mono** for code/log lines. (Do not assign Satoshi to UI — that's an inversion.) Headings at `font-weight 600`, display tracking `-.025em`, uppercase eyebrows `+.05–.1em`.
- **Motion** — Exactly **ONE** timing function across all transitions: `cubic-bezier(.4,0,.2,1)` at .15s. There is **no** secondary "hero curve" (the often-cited `cubic-bezier(.87,0,.13,1)` does NOT exist here — and where it *does* appear on other sites it's accordion-only). Motion restraint IS the signature — opacity-only fades (`fade-in-50`/`fade-in-80`). Real site-specific moves: feature-card icons nudge `translate-x-[3px] translate-y-[-3px]` (300ms ease-in-out); a `moving-lines` diagonal-PNG background scrolls on card hover.
- **Spacing** — CSS-grid shell (`grid-rows-[auto,1fr,auto] min-h-screen`), large section padding, centered max-width, line-height ladder 1 → 1.5 → 1.75.
- **Color** — Pure-black body with a **bespoke cool-charcoal** ramp (`charcoal-100 #E8E9EC … charcoal-1000 #0B0C0F`, primary bg `#121317`), never generic dark-gray. ONE **acid-lime** accent **`#a8ff53`** (token `primary`/`apple-500`) — outline, fill, hover-underline, plus `#a8ff531a` 10%-alpha chips. A true **second** accent exists: lavender **`#7655fd`** (token `--secondary`) on heading text, focus rings, icons (not gradient-only).
- **Micro-interactions** — Glassmorphism on pill/announcement banners (backdrop-blur over `bg-black/20`) — **not** on the nav (the header is solid `#121317` with a 1px border). Hover = the lime text-decoration + diagonal icon nudge; 1px hairlines `#303236`.
- **Relation to `linear.app`** — Shares the dark-first near-black, single dominant accent, tight tracking, sub-200ms `cubic-bezier(.4,0,.2,1)`, hairlines. Diverges with a **louder acid-lime** accent, a **rounder Satoshi** display voice, and Geist Mono elevated because the product *is* code.
- **Signature:** one electric-lime `#a8ff53` token doing all the work — outline, fill, hover-underline — on a bespoke cool-charcoal canvas, plus the `moving-lines` diagonal-scroll card hover.

### `turso.tech` — mint-aqua, fill-CTA-with-black-text
- **Typography** — **Inter** for display AND body (`body{font-family:var(--font-inter)}`), with aggressive `letter-spacing:-.03em` on large/heading text (tighter than Linear's -.02em); body at `1rem/150%`, never letterspaced. (Note: the `.font-ibm-plex-mono` class is **dead** in production — no `@font-face` loads it; eyebrow labels use Inter via `.turso-label` at `.1em` uppercase. Reserve real mono for code only.)
- **Motion** — Stock Tailwind defaults (`cubic-bezier(.4,0,.2,1)` at .15s) — NOT a signature. Nav/link hover swaps are **instantaneous** (no `.transition` class); only the orange... [aqua] CTA animates. The one site-specific keyframe is `animate-floating` (`translateY(15px)` at 50%, 3s ease-in-out infinite). (No `prefers-reduced-motion` — don't copy.)
- **Spacing** — `max-w-7xl` (1280px) centered, copy narrowed to `max-w-3xl`; rounded `xl/2xl/full` geometry; faint **dot-grid** texture: `radial-gradient(#e5e7eb 1px, transparent 1px)` at 16px, ellipse-vignette-masked, wrapper at **opacity-5** (a near-invisible *light* texture — use #e5e7eb at 5%, not a thematic color).
- **Color** — Dark-first (`bg-bunker text-white`). Official brand neutrals: Bunker `#0D1318`, Mirage `#162129`, Dark Teal `#183134`, Pickled Bluewood `#293945`. ONE **warm-mint accent** Turso Aqua **`#4FF8D2`** (`#4FF7D1` in markup) — and the iconic move: primary buttons are **aqua FILL with BLACK text** (`bg-[#4FF7D1] text-black`), the inverse of a dark-UI ghost button. A genuine **second accent at rest**: fuchsia-500 `#ec4899` on "new feature" pill badges + secondary CTAs (not hover-only).
- **Micro-interactions** — Hairline card borders `#283945` flipping to aqua `#4FF7D1` on hover; on hover muted text lifts to full white (`hover:text-white`); never layout-shifting. Focus via `ring-1 ring-inset`.
- **Relation to `linear.app`** — Same dark-first, neutral untinted ladder, hairlines-not-shadows, sub-200ms `cubic-bezier(.4,0,.2,1)`. Diverges with a **warm mint accent** + black-text fill CTA, a deliberate **second** (fuchsia) accent, softer rounded geometry, and IBM-Plex-style ASCII/mono cues.
- **Signature:** the aqua-fill / black-text primary button — `bg-[#4FF7D1] text-black` — on a Bunker-black canvas with mint hairline-flip hovers.

### `outstatic.com` — neo-brutalist serif hero, monochrome zinc
- **Typography** — Hero is a **SERIF** (`font-serif text-5xl md:text-7xl lg:text-8xl leading-[0.9] tracking-tight`) — huge, line-height 0.9, width-capped, centered. (Caveat: the `font-serif` Tailwind class resolves to the *system serif* stack — Lora is loaded but `--font-serif` is not wired to it; to actually ship Lora, add `--font-serif: var(--font-lora)`.) Inter for UI, system mono for code. Highlight ONE word with an **achromatic gradient clip** (`from-black via-zinc-600 to-slate-600 bg-clip-text`).
- **Motion** — Standard Tailwind only: `cubic-bezier(.4,0,.2,1)` at .15s — **no overshoot/spring curves exist** (the often-claimed `--ease-snappy`/`--ease-swift` are NOT in the bundle). Real motion: `fade-in-up` (ease-out, staggered `animation-delay`), feature-card icon `group-hover:-translate-y-2`, an `animate-write` SVG stroke-draw (1s ease-out, 0.8s delay, md+ only). The motion system is *more* restrained than it looks.

## How to use this

These 19 sites are the **default taste layer**, not a gallery. When an OmegaOS design skill (`design-system`, `high-end-visual-design`, `image-to-code`, `stitch-design-taste`, `taste-skill`, the `*-ui` skills) generates UI with no contrary brief, it builds to **this bar** — Linear/Vercel-tier — automatically.

- **Start from the Anchor.** `linear.app` is the measuring stick: near-black canvas, one cool accent, Inter at weight 600 max with size-proportional negative tracking, 4px spacing on a 96px section beat, depth from a surface ladder + 1px hairlines (never shadow-glow), motion that suppresses itself on high-frequency surfaces.
- **Pick a dialect, not a pastiche.** Each entry is a *coherent deviation* on one or two axes (warm accent, serif display, light-first, multi-channel color, OKLCH, TUI texture). Choose one temperature and commit — never mix three sites' accents into a soup.
- **Steal discipline, not hex blindly.** Where the ledger verified a value (shipped CSS / live DOM), use it. Where it was third-party-inferred, unreachable, or "reads as," phrase the output the same way — do not invent false precision (e.g. a cubic-bezier the site never ships).
- **The grep test.** A default OmegaOS UI should be indistinguishable from a Tier-1 clone — one accent, hairline structure, tight tracking, dark-first depth, motion restraint. If it reads "generic Tailwind template," it failed the bar; return here and raise it.
