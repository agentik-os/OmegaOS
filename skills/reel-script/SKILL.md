# Reel Script — script calibré, pas au feeling

Tu écris un script de reel face cam prêt à lire au téléprompteur. Chaque règle ci-dessous vient de patterns MESURÉS sur des reels à +100K vues. Aucune n'est optionnelle.

## Structure obligatoire

1. **Hook (0-5 s)** — un CHIFFRE concret dans la première phrase (prix, durée, nombre, vues). Choisir UN pattern :
   - *Contraste financier* : « [Petit montant] pour [résultat énorme]. Ce n'est pas une astuce. »
   - *Kill* : « [Outil/IA] vient de tuer [métier/outil cher]. »
   - *Contrarian* : « Tout le monde fait [X à la main]. Voici pourquoi ils perdent. »
   - *Combo* : « [Outil A] + [Outil B] = triche pure. »
   - *Révélation d'outil* : « Désormais [capacité] totalement gratuitement. » (le NOM de l'outil arrive APRÈS le désir, jamais dans le hook)
2. **First-person testé** : « j'ai testé / j'ai branché / j'ai reconstruit » — jamais de théorie.
3. **Boucle ouverte** : « Je vais te montrer en 3 étapes comment… » (et TENIR les 3 étapes, numérotées).
4. **Cliffhanger** avant la dernière étape : « Mais attends, ce n'est même pas le plus fou. »
5. **Un outil concret nommé** : un repo GitHub (slug exact), un MCP, un plugin ou une commande — la valeur vient de la CONNEXION, pas de l'outil seul.
6. **Reframe** : l'IA = un rôle humain (« ce n'est pas ton outil, c'est ton employé »).
7. **CTA** : « Commente ce que tu veux, et abonne-toi. Je t'envoie [la ressource] en DM. » Jamais de mot-clé imposé.

## Règles de forme

- **≤ 175 mots** au total (≈ 60 s à 2,9 mots/s). Couper, pas compresser.
- **Phrases très courtes.** Une idée par ligne. Retour à la ligne à chaque phrase (lecture téléprompteur).
- **1 à 3 power words**, naturellement : littéralement, FOU, une multitude de, énorme, méconnu.
- **Chiffres honnêtes** : attribuer les résultats (« ce créateur », « mon résultat ») — jamais promettre au viewer.
- Tutoiement, registre direct, zéro jargon inexpliqué.

## Format de sortie

Rendre : le SCRIPT complet (une phrase par ligne) + 3 variantes de hook labellisées (A retenue, B, C) + la caption + une idée de démo écran à capturer pour chaque étape.
