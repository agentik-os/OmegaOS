# Marketing Mastery — Alignment Matrix (doctrine ↔ executing skills)

> **What this is.** The *Marketing Mastery* manual (FR, author Atlas/OmegaOS, 12 Parts) is the
> **doctrine layer** of OmegaOS marketing. This matrix maps every sub-section of the book onto
> OmegaOS's **existing tactical skill library**, so the doctrine and the execution never duplicate
> each other — they compose.
>
> - **Doctrine (the `mm-XX` skills — 12 new, one per Part, + 1 `marketing-master` orchestrator).**
>   The *why*, the *when*, the *sequence*, and the mental models — Dunford, Moesta/Christensen,
>   Schwartz, Cialdini, Hormozi, Sharp, Chen, Weinberg, Balfour — recalibrated for 2026-2027
>   (zero-click, GEO, AI-saturated content, distribution > product). A `mm-XX` skill **decides
>   which executing skill to invoke, in what order, and why.** It never re-implements them.
> - **Execution (the existing skills — `mk-*`, `ads-*`, `ag-seo-*`, `market-*`, `creator-media-engine`,
>   `audience-growth-engine`, `product-marketing-context`, `marketing-strategist`, the `*audit`
>   forensics, …).** The *how*: produce the artifact — write the copy, build the funnel, generate the
>   ad, set the price, instrument the metric, run the audit.
>
> **No duplication contract.** Doctrine routes; tactics produce. Where a doctrine concept already has
> a tactical home, the `mm-XX` skill cites it (column *Executing tactical skill(s)*, status ✅). Where a
> concept is pure judgment/strategy with no executing artifact (e.g. *the JTBD switch interview*,
> *community-as-moat*, *taste*), the `mm-XX` doctrine skill **is its home** (status 📘).
