## 2. programmatic-seo

**Source:** `~/.agents/skills/programmatic-seo/`

### Quand l'utiliser

- Créer pages SEO à scale
- Template pages
- Directory pages
- Location pages (keyword + city)
- Comparison pages
- Integration pages

### Concept

Générer des pages SEO-optimized automatiquement à partir de templates et données structurées.

### Exemple use case

```
Template: "Best {service} in {city}"
Data:
- Services: [plumber, electrician, painter]
- Cities: [Paris, Lyon, Marseille]

→ Génère 9 pages optimisées
```
