01L'essentiel

OmegaOS a désormais trois surfaces de rapport, routées par la nouvelle règle R-ARTIFACT :

  • Surface 1 (défaut) : un rapport demandé sans format devient un artifact live publié sur claude.ai (privé par défaut, partageable à l'org, URL stable versionnée), avec son jumeau HTML commité sous agentic/reports/.
  • Surface 2 : le fichier HTML autonome (R-HTML, désormais compilé dans le registre), quand un fichier est voulu ou quand la session n'a pas l'outil Artifact.
  • Surface 3 : le PDF, uniquement sur demande explicite, via omega pdf (R-PDF).

Le skill artifact-design (155 lignes) exécute le protocole : contrat de design autonome, passe anti-tirets (R-NODASH), repli HTML explicite, publication et re-publication à URL stable.

07Limites et périmètre

  • La surface artifact exige une session interactive éligible (bêta Team/Enterprise) : les runs headless et cron replient vers la surface 2 et le disent. C'est encodé dans la règle et le skill, pas contourné.
  • Cas non testé au runtime : la résolution du nom artifact-design quand le skill utilisateur ET le natif coexistent dans une session interactive. Borné par conception : le routage vit dans R-ARTIFACT (injecté partout) et le skill OmegaOS est autonome en design ; l'issue est sûre quelle que soit la copie résolue.
  • La génération visuelle du contenu reste soumise à R-CITE : chaque affirmation de cette page porte sa preuve (fichier:ligne, sonde, source datée).
