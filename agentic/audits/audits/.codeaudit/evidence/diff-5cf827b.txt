    fix(tui): Esc in chat focus returns to the session list — local, never forwarded (F-2)
    
    Esc while chat-focused (Chat AND ChatFullscreen) now drops back to the
    session list inside the TUI instead of being forwarded to the live agent
    (which interrupted a running Claude turn). Matches the three surfaces
    already promising this (title hint, Help tab, layered-Esc pattern).
    Interrupting the agent stays available via Ctrl+C. The previously dead
    inner Esc arm (unreachable behind the chat router) is removed.
    
    Runtime-verified BEFORE/AFTER on rmux harness — evidence in
    audits/.fixes/evidence-fix2/ (^[ count unchanged across split +
    fullscreen Esc; C-c still delivered).
