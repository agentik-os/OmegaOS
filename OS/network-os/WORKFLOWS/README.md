# Network {OS}: Workflows

Repeatable processes this OS runs. Each workflow is one file, named for what it
produces, and states its trigger, steps, and completion test.

| Workflow | Trigger | Produces |
|---|---|---|
| [Consented introduction](consented-introduction.md) | two people would genuinely both gain from knowing each other | two consent records and an introduction sent only after both |
| [Interaction capture](interaction-capture.md) | a conversation ends, or Meeting {OS} publishes a record | an interaction record and every commitment with an owner and a date |
| [Network review](network-review.md) | the review cadence fires, or the network feels one-sided | every relationship classified as active, breathing, dropped or unassessed |
