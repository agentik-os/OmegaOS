## 1. Selection rule

Choose a method because it attacks the current uncertainty. Use 2–4 methods per standard cycle, not every framework.

| Need | Preferred methods |
| --- | --- |
| Wrong or narrow frame | Five Whys, abstraction ladder, HMW, jobs/outcomes |
| Incremental ideas | first principles, inversion, constraint removal, extreme scale/time |
| One inherited worldview | Founder DNA, Frame Fission, counterfactual worlds |
| Many cosmetic variants | idea genome, multi-locus mutation, crossover, speciation, extinction |
| Novelty without value | valuable-surprise test, causal chain, founder-signature fit |
| Platform chosen too early | Surface Lab, no-interface inversion, moment-to-affordance map |
| Mobile/web/desktop ambiguity | native-affordance matrix, discriminating prototype, multi-surface role map |
| Similar-looking options | morphological matrix, mechanism taxonomy, forced orthogonality |
| Hidden contradictions | dialectic, paradox map, TRIZ-style contradiction resolution |
| Complex effects | causal-loop map, systems boundaries, stocks/flows, second-order effects |
| Weak user value | JTBD, pains/gains, switching forces, trust/friction journey |
| Fragile strategy | alternatives map, wedge, value chain, moat decay, game theory |
| Business ambiguity | value-flow map, incentive compatibility, unit/economic sensitivity |
| Overcomplexity | subtraction, 10×/10%, minimum magical version |
| Premature confidence | premortem, base rates, assumption mapping, falsification |
| Hard choice | weighted matrix, regret minimization, reversibility, sensitivity analysis |
| Unknown truth | experiment ladder, concierge test, smoke test, prototype, research task |

## 2. Framing and first principles

### Abstraction ladder

Move upward from feature to outcome and downward from outcome to mechanisms. Stop when alternatives become meaningfully different.

### First-principles decomposition

List:

1. desired state change;
2. actors and resources;
3. physical, human, legal, and economic constraints;
4. inherited conventions that are not constraints;
5. minimum causal chain that creates value.

Rebuild from the causal chain.

### Inversion

Ask:

- How would we guarantee failure?
- What if the user never performs the assumed behavior?
- What if the opposite actor pays?
- What if scarcity, speed, privacy, ownership, or automation is reversed?
- What if the “problem” is protective or desirable?

Convert inverted insights into constraints or novel mechanisms.

## 3. Divergence

For multi-generation ideation, Founder DNA, Frame Fission, idea genomes, collisions, counterfactual worlds, anomalies, and incubation, use [imagination-and-evolution.md](imagination-and-evolution.md). For embodiment choice, use [surface-lab.md](surface-lab.md).

### Morphological matrix

Choose 4–7 dimensions, list 3–6 mechanisms per dimension, and combine only compatible cells. Example dimensions: actor, trigger, value unit, interaction, trust, revenue, distribution, fulfillment.

### SCAMPER

Use Substitute, Combine, Adapt, Modify, Put to another use, Eliminate, Reverse only when an existing mechanism needs transformation. Do not use as the primary method for an undefined problem.

### Distant analogy

Map source domain → deep mechanism → target constraint → adapted mechanism. Reject surface imitation.

### Constraint transformations

For a key constraint, try:

- remove it;
- make it 10× tighter;
- make it the product;
- transfer it to another actor;
- convert it into a trust or status signal;
- delay or stage it.

### Minimum magical version

Remove every element that does not directly create the distinctive transformation. Preserve the “magic,” not the feature set.

## 4. Contradiction and systems

### Paradox map

For tensions such as exclusivity vs growth or automation vs trust:

1. define why each pole creates value;
2. show the failure of optimizing either alone;
3. separate by actor, time, context, tier, or object;
4. seek a mechanism that changes the tradeoff;
5. if unresolved, choose explicitly.

### Causal-loop reasoning

Identify reinforcing loops, balancing loops, delays, bottlenecks, externalities, and threshold effects. State causal direction in words before drawing a diagram.

### Premortem

Assume failure despite competent execution. Build a causal story, leading indicators, prevention, contingency, and kill threshold. Avoid generic lists like “competition” or “bad marketing.”

### Anti-goal

Describe a version that achieves the metric but violates the mission. Convert it into guardrails and counter-metrics.

## 5. Human, strategy, and economics

### JTBD and switching forces

Define functional, emotional, and social progress. Map push of current situation, pull of new solution, anxiety of change, and habit of present behavior.

### Trust/friction journey

At each step ask: what does the actor know, fear, expose, risk, control, and receive? Distinguish useful friction from accidental friction.

### Alternatives and wedge

Include non-consumption, manual work, status quo, and adjacent category—not only direct competitors. Define the smallest group with acute pull and a mechanism that can expand without breaking the core.

### Value and incentive flow

Map who contributes assets, attention, data, labor, capital, access, or reputation; who receives value; who pays; who bears risk; and who can game the system. Examine adverse selection and principal-agent problems.

### Defensibility decay

For each claimed moat, ask how quickly it can be copied, subsidized, regulated, disintermediated, or made irrelevant. Prefer compounding assets and trusted systems over novelty claims.

## 6. Convergence and experiments

### Decision matrix

Use criteria derived from the frame, not generic defaults. Include weights, scores, confidence, evidence note, and sensitivity. Flag any winner that depends on a fragile weight or unsupported score.

### Reversibility and regret

Classify:

- two-way door: decide quickly, instrument, revisit;
- one-way door: demand more evidence and premortem;
- sequencing decision: choose what must be learned first;
- value decision: return to founder rather than pretending it is factual.

### Experiment ladder

Choose the cheapest method capable of changing the decision:

1. source/research check;
2. expert/user interview;
3. message or concept test;
4. paper prototype;
5. concierge/manual delivery;
6. smoke test or commitment signal;
7. functional prototype;
8. limited pilot.

For each experiment define hypothesis, risky assumption, target actor, method, cost/time, leading signal, success/failure threshold, confounds, ethics, and next decision.

### Confidence calibration

Use qualitative confidence (`low`, `medium`, `high`) and explain the evidence class. Reduce confidence when claims rely on intuition, a single source, proxy behavior, or unprecedented coordination.
