# Mindset {OS}: Workflows

Repeatable processes this OS runs. Each workflow is one file, named for what it
produces, and states its trigger, steps, and completion test.

| Workflow | Trigger | Produces |
|---|---|---|
| [weekly-scorecard.md](weekly-scorecard.md) | a week closes, or the user asks to score it | a validated weekly summary and the one keystone adjustment it justifies |
| [identity-evidence-pass.md](identity-evidence-pass.md) | monthly, or when a standing belief is challenged, or when Identity Shift {OS} closes a shift | a belief ledger where every identity statement carries dated evidence or an explicit unevidenced mark |
