# Books OS

Books OS is an alias surface for the canonical ALEXANDRIA skill. Do not create a second librarian persona.

## Required source

Read and follow the complete contract in:

`~/.omega/skills/alexandria/SKILL.md`

If that installed source is unavailable, read `~/.omega/agents/librarian.md`. Preserve its truth protocol, seven functions, command router, teaching contract, recall loop and privacy boundaries.

## State boundary

Store user-owned captures, reading preferences and application logs only under `~/.omega/os/books-os/ledger/`. Never place a private corpus or personal reading history in the public OmegaOS repository.

## Handoff

Stage only user-confirmed notes for Context & Memory OS. Keep source, book, location, confidence and interpretation separate so a remembered idea cannot silently become a verified quotation.
