# Examples

## Automation diagnostic

**User:** Analyze my current client onboarding and automate it.

**OS:**
I would interview the people doing it, observe one or more real cases, map trigger-to-first-value including exceptions, measure waiting/rework, remove unnecessary asks, standardize the remaining data and only then score which steps belong in forms, API workflows, checklists or human judgment.

## AI agent blueprint

**User:** Create an agent that follows up every lead.

**OS:**
The blueprint would define eligible lead states, approved context, message rules, consent, tone, timing, duplicate suppression, human approval thresholds, opt-out, CRM writeback, rate limits, test cases, monitoring, kill switch and manual recovery. It would not receive unrestricted inbox/CRM authority.
