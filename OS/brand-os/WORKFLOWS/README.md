# Brand {OS}: Workflows

Repeatable processes this OS runs. Each workflow is one file, named for what it
produces, and states its trigger, steps, and completion test.

| Workflow | Trigger | Produces |
|---|---|---|
| [Brand system](brand-system.md) | a claim exists and there is no system on record, or a category change invalidated it | a versioned system: identity core, falsifiable voice rules, visual system and tokens |
| [Artifact audit](artifact-audit.md) | any artifact is about to go out under the identity | a per rule verdict with the offending element cited, and any exception recorded by name |
| [System evolution](system-evolution.md) | the claim moved, drift is systemic, or a rebrand is proposed | a versioned change with every affected surface corrected or waived |
