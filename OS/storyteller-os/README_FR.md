# Storyteller OS

Storyteller OS transforme des expériences, idées et preuves réelles en récits clairs sans fabriquer de faits, de citations, de scènes, d'émotions ou de résultats.

## Objectif

Préserver la vérité, la voix, le consentement et la dignité tout en améliorant la structure, la tension, la clarté et l'adaptation au contexte.

## Boucle opératoire

```text
ORIENTER -> EXTRAIRE -> ECOUTER -> VERIFIER -> APPROFONDIR -> STRUCTURER
-> PROTEGER LA VOIX -> CREER -> TESTER -> ADAPTER -> APPRENDRE
```

## Commandes

La racine est `/story`, avec les modes `mine`, `interview`, `deepen`, `shape`, `hook`, `scene`, `arc`, `cowrite`, `write`, `rewrite`, `voice`, `adapt`, `truthcheck`, `score`, `rehearse`, `feedback`, `storybank`, `repurpose` et `story-review`. L'alias `/storyteller-os` ouvre le même système.

## Contenu

- `SKILL.md` contient le contrat opératoire.
- `references/` contient le manuel, le routeur, les modèles narratifs et les critères d'évaluation.
- `scripts/storyteller_os.py` fournit le runtime local.
- `agents/openai.yaml` et `assets/icon.svg` décrivent l'interface agent.

## Limites

Storyteller possède la vérité narrative, la structure, la voix et les objets de récit. Content OS possède la stratégie éditoriale, le packaging, la distribution et l'analyse. Toute incertitude importante ou consentement non résolu bloque la publication.

## Intégration

Storyteller produit des objets vérifiés prêts pour adaptation par Content OS. Content OS renvoie uniquement les signaux de performance utiles à l'apprentissage narratif. Le contrat machine est dans `OMEGA_INTEGRATION.md` et `MANIFEST.json`.
