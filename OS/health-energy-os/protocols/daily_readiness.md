# Protocol — Daily Readiness

1. Record sleep opportunity, perceived quality, energy, soreness, stress and symptoms.
2. Compare with the personal 7–28 day baseline, not generic perfection.
3. Run the safety gate.
4. Select GREEN / AMBER / RED capacity.
5. Keep, reduce or replace planned load.
6. Send the capacity constraint to Execution OS.

## Required closure
- decision or output
- owner
- observable completion evidence
- review trigger
- memory/handoff instruction
