# Health & Energy OS, v1.0.0

**Category:** Personal Stack / Health Capacity  
**Omega position:** Personal Stack: upstream capacity provider for Habit, Execution and Strategy & Portfolio OS  
**Primary interface:** conversational + structured records  
**Status:** installable reference implementation

## Purpose
Build and protect the user’s physical and cognitive capacity through sleep, movement, training, nutrition, recovery, stress regulation, environment and appropriate professional care.

## Promise
Turn fragmented symptoms, routines and wearable signals into safe, sustainable experiments and clearer decisions, without pretending to diagnose or replace clinicians.

## Core equation

```text
CAPACITY = SLEEP × MOVEMENT × FUEL × RECOVERY × MEDICAL SAFETY × SUSTAINABILITY
```

## Operating loop

```text
BASELINE → SAFETY GATE → CAPACITY DIAGNOSIS → MINIMUM EFFECTIVE PLAN → EXPERIMENT → TRACK → REVIEW → ADAPT / ESCALATE
```

## What this OS contains
- Canonical system prompt and explicit boundaries
- 12 specialist agents
- 18 reusable skills
- 8 operating protocols
- domain memory and privacy model
- JSON schemas for 6 core entities
- evaluation suite and adversarial tests
- provider-neutral reference runtime
- curated book canon and source ledger

## Commands
| Command | Mode | Purpose |
| --- | --- | --- |
| `/health` | check-in | Open Health & Energy OS |
| `/readiness` | check-in | Assess today’s capacity |
| `/health-audit` | audit | Build a baseline |
| `/sleep` | audit | Audit sleep and circadian constraints |
| `/training` | plan | Build or revise training |
| `/nutrition` | plan | Review fuel and adherence |
| `/recovery` | recovery | Respond to fatigue or overload |
| `/travel-health` | travel | Design a travel protocol |
| `/health-experiment` | experiment | Create an N-of-1 experiment |
| `/wearable` | explain | Interpret trends conservatively |

## Main handoffs
- Habit Tracker OS receives agreed routines, not raw medical files.
- Execution OS receives a capacity status and workload constraints.
- Strategy & Portfolio OS receives sustainable capacity assumptions.
- Qualified professionals receive a concise question pack when escalation is needed.
