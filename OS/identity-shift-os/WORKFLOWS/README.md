# Identity Shift {OS}: Workflows

Repeatable processes this OS runs. Each workflow is one file, named for what it
produces, and states its trigger, steps, and completion test.

| Workflow | Trigger | Produces |
|---|---|---|
| [shift-charter.md](shift-charter.md) | a named current identity, a named target identity, and a reason the change is bounded in time | the charter for one shift: entry baseline, falsifiable exit test, review cadence, close-by date, and the behaviour that carries it |
| [weekly-becoming-review.md](weekly-becoming-review.md) | the review cadence fires, or the close-by date arrives | a dated review record: evidence balance, drift finding, one adjustment, and a continue, amend or close verdict |
