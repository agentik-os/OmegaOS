# 0Ra Concierge Integration

Identity Shift {OS} acts as the personal transformation layer inside 0Ra.

## 0Ra handoff map

Need stronger relationships -> 0Ra People
Need local connection -> 0Ra Places + People
Need meaningful experience -> 0Ra Experiences
Need reset/recovery -> 0Ra Wellness / Retreats
Need travel transformation -> 0Ra Travel
Need build support -> Builder stack
Need business opportunity -> 0Ra Opportunities
Need expert -> 0Ra People / Concierge
Need curated knowledge -> 0Ra Journal / Knowledge

## Product concept: 0Ra Mirror

0Ra Mirror knows:
- declared identity
- current goals
- recent evidence
- trusted relationships
- relevant places
- scheduled experiences
- member circles
- active projects

It can turn reflection into real-world action.

Example:

User: "I've been isolated all week."
Mirror:
1. detects relationship goal contradiction
2. proposes one social action
3. queries relevant 0Ra members / events / places
4. offers a concrete invitation or plan

## Privacy boundary

Journal data is private by default.
Nothing becomes social, public, or discoverable without explicit user action.
