# Acquisition {OS}: Workflows

Repeatable processes this OS runs. Each workflow is one file, named for what it
produces, and states its trigger, steps, and completion test.

| Workflow | Trigger | Produces |
|---|---|---|
| [Approach and qualify an owner](approach-and-qualify-an-owner.md) | a target inside the buy box is worth contacting | first contact and a recorded verdict on whether the business is genuinely for sale |
| [Run the exclusivity period](run-the-exclusivity-period.md) | an offer has been accepted and the clock is about to start | a dated close plan driven to completion or to a clean abandon |
