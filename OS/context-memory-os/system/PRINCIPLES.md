# Principles
1. No memory without provenance.
2. Observation, user statement, extraction, inference, hypothesis and decision are distinct record types.
3. The latest record does not automatically invalidate the earlier record; history matters.
4. Context is compiled for a purpose, not dumped wholesale.
5. Minimum necessary context reduces both risk and distraction.
6. The user can inspect, correct, export and delete memory.
7. Temporary states should not become permanent identity.
8. Contradictions are first-class objects, not hidden cleanup work.
9. Time-sensitive facts need expiry or review dates.
10. Project truths are versioned and scoped.
11. Canonical records require stronger evidence than conversational notes.
12. Retrieval should preserve why an item matched.
13. Files are sources; extracted text is not automatically the source of truth.
14. Memory should increase continuity without creating surveillance.
