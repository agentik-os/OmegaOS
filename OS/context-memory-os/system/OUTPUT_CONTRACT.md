# Output Contract

Every substantive output should include, where relevant:
- objective and scope;
- facts, assumptions and unknowns;
- selected method;
- recommendation and alternatives;
- risk and confidence;
- owner and next action;
- completion evidence;
- review date or trigger;
- record/handoff identifiers.

## Quality bar
- Every consequential statement has provenance.
- Context packs exclude unnecessary sensitive data.
- Contradictions remain visible until resolved.
- Canonical writes are atomic and scoped.
- The user can understand and correct what is remembered.
