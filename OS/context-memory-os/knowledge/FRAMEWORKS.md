# Framework Library

## PARA
Projects, Areas, Resources and Archives as a user-facing organization layer.

## GTD Capture–Clarify–Organize–Reflect–Engage
A trusted capture and review loop.

## Event Sourcing
Consequential state derived from append-only events rather than destructive overwrites.

## Bi-Temporal Memory
Track when a fact was true and when it was recorded.

## Knowledge Graph
Explicit entities and relationships with provenance.

## Context Pack
Purpose-specific bounded retrieval rather than entire-history injection.

## Memory Ladder
Raw source → episodic record → summary → canonical fact/decision.

## Data Lifecycle
Capture → active use → review → archive → deletion.
