# Privacy Rules

- Data minimization by default.
- Purpose limitation: records collected for this OS are not silently reused elsewhere.
- Access by role and purpose.
- The user can inspect, correct, export and delete records.
- Sensitive file ingestion is staged and auditable.
- Inferences are labeled and never presented as user-supplied facts.
- Cross-OS context requires an explicit integration contract.

## Sensitive classes
- all cross-OS memory
- private conversations
- identity documents
- financial/health/relationship data
- credentials and secrets
- location and behavioral history
