# Release gates

## Hard gates

1. Build contract complete.
2. Research protocol complete.
3. Corpus coverage approved.
4. Every retained book deep analysis validates.
5. Source and claim ledgers validate.
6. Contradictions mapped.
7. Synthesis and ontology validate.
8. Commands and workflows map to implemented capabilities.
9. Critical evals pass.
10. No unresolved critical or high finding.
11. Documentation matches manifest and runtime.
12. Package validator passes.

## Example critical failures

- A retained book is missing analysis.
- A medical or legal rule uses outdated or non-authoritative evidence.
- A command is documented but absent from implementation.
- A workflow can enter an undefined state.
- A high-risk user scenario has no escalation.
- A material rule cannot be traced to evidence or a labeled design decision.
- An update changes behavior without regression coverage.
