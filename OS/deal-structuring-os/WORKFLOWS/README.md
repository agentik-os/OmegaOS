# Deal Structuring {OS}: Workflows

Repeatable processes this OS runs. Each workflow is one file, named for what it
produces, and states its trigger, steps, and completion test.

| Workflow | Trigger | Produces |
|---|---|---|
| [Model the waterfall before agreeing terms](model-the-waterfall-before-agreeing-terms.md) | a term is proposed by either side | the cash each party receives at low, middle and high exits, with and without the term |
| [Reconcile executed documents](reconcile-executed-documents.md) | documents arrive from the lawyers | a line by line comparison against agreed terms, with every difference raised before completion |
