# Intuitive {OS}

An evidence-calibrated operating system for training high-level intuition through observation, pattern recognition, probabilistic forecasting, decision journaling, feedback, and deliberate calibration.

## Mission
Turn vague instinct into a measurable learning loop without treating feelings as facts.

## Core loop
OBSERVE -> CAPTURE -> CLASSIFY -> PREDICT -> DECIDE -> OUTCOME -> REVIEW -> CALIBRATE -> COMPRESS -> REPEAT

## Commands
- `/intuition setup` create domains, baselines and training cadence
- `/intuition capture` capture a raw intuition before analysis
- `/intuition predict` log a falsifiable probabilistic prediction
- `/intuition decide` run the decision protocol
- `/intuition signal` inspect a weak signal without over-interpreting it
- `/intuition counter` red-team an intuition
- `/intuition review` resolve predictions and extract lessons
- `/intuition daily` daily training session
- `/intuition weekly` weekly calibration review
- `/intuition patterns` maintain the pattern library
- `/intuition models` train mental models
- `/intuition profile` generate domain-specific intuition profile
- `/intuition 90d` run the 90-day curriculum

Read `SKILL.md` and `prompt/INTUITIVE_OS_SYSTEM.md` first.
