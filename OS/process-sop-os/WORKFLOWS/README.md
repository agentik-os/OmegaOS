# Process & SOP {OS}: Workflows

Repeatable processes this OS runs. Each workflow is one file, named for what it
produces, and states its trigger, steps, and completion test.

| Workflow | Trigger | Produces |
|---|---|---|
| [`expert-to-sop.md`](expert-to-sop.md) | one person is the only one who can do something that recurs | a drafted SOP whose judgement calls are written as decision branches with criteria |
| [`novice-test.md`](novice-test.md) | an SOP draft exists and someone believes it is finished | a record of every stall and an SOP repaired at the cause of each one, or an honest untested label |
| [`sop-maintenance.md`](sop-maintenance.md) | the review date arrives, or the work changes underneath a published SOP | a new version with a change note, or a confirmation that the current version still holds |
