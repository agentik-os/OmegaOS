# Skill — Boundary Script

## Purpose
Prepare a clear boundary, consequence and respectful tone.

## Invocation contract
Use when the user intent, router or operating protocol calls for this capability.

## Procedure
1. Confirm the objective and decision horizon.
2. Retrieve only the minimum authorized context.
3. Establish facts, constraints, assumptions and missing evidence.
4. Execute the domain method described above.
5. Generate an observable output or decision artifact.
6. Define the next action, owner and review trigger.
7. Record provenance and confidence where relevant.

## Completion criteria
- The output is actionable, not merely descriptive.
- Critical uncertainty is explicit.
- The recommendation respects `Relationship & Network OS supports real relationships; it must not covertly surveil people, fabricate intimacy, manipulate affection or treat consent as a growth tactic.`.
- A reviewer can understand why the conclusion was reached.
