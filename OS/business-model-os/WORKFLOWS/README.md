# Business Model {OS}: Workflows

Repeatable processes this OS runs. Each workflow is one file, named for what it
produces, and states its trigger, steps, and completion test.

| Workflow | Trigger | Produces |
|---|---|---|
| [business-model-canvas.md](business-model-canvas.md) | an idea, plan or running business has no single written statement of how it creates, delivers and captures value | the model on one page: segments, value proposition, delivery mechanism, channels, revenue mechanics, cost structure and dependencies, with every unknown marked unknown |
| [unit-economics-model.md](unit-economics-model.md) | the canvas exists and someone needs to know whether one unit makes money | contribution, acquisition cost, retention, payback and lifetime value on a countable unit, every input origin-labelled |
| [viability-assessment.md](viability-assessment.md) | unit economics exist and someone is about to build, fund, hire against or continue the model | the verdict against a bar stated first, with breakeven volume set against the volume the pipeline can plausibly produce |
| [model-variant-comparison.md](model-variant-comparison.md) | the question is which model shape to run, not whether the business works | two or three shapes compared on identical assumptions, each with what must be true for it to win |
