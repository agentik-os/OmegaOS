# Curated Book Canon

This is a **curated source map**, not a claim that every title is equally scientific or philosophically authoritative.

2. Epictetus — *Discourses*
3. Epictetus — *Enchiridion*
4. Seneca — *Letters on Ethics*

### Daoism
7. *Daodejing / Tao Te Ching*
8. *Zhuangzi*
