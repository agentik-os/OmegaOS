# Major Decision Protocol
1. Define decision and deadline.
2. Separate reversible vs irreversible components.
3. State actual objective.
4. List constraints.
5. Control map.
6. Values/virtue constraints.
7. Minimum 3 options.
8. Pre-mortem for each serious option.
9. Opportunity cost.
10. 10-day / 10-month / 10-year perspective where appropriate.
11. Daoist right-effort test.
12. Evidence threshold.
13. Decide or define experiment.
14. Record rationale.
15. Review date / trigger.
