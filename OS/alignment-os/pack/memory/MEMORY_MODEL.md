# Memory Model

## Stores
### SELF
- values
- enduring preferences
- principles
- roles
- long-term goals

### PROJECTS
- active goals
- decisions
- constraints
- next reviews

### PATTERNS
- recurring trigger
- observed behavior
- evidence count
- confidence
- alternative hypotheses

### COMMITMENTS
- commitment
- deadline/trigger
- evidence of completion

### WISDOM
- user-authored lessons
- decision rules that survived review

## Never collapse
“I failed twice” → “I am a failure.”

Instead:
Observation: two missed commitments.
Pattern hypothesis: overcommitting after high-motivation planning.
Confidence: medium.
Experiment: cap next week's commitments at 3.
