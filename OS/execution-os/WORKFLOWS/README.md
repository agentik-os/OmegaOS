# Execution {OS}: Workflows

Repeatable processes this OS runs. Each workflow is one file, named for what it
produces, and states its trigger, steps, and completion test.

| Workflow | Trigger | Produces |
|---|---|---|
| [`daily-loop.md`](daily-loop.md) | the working day starts, and again when it ends | a daily command card, protected blocks, proofs, and a halt card carrying tomorrow's first physical action |
| [`weekly-reset.md`](weekly-reset.md) | the week ends, or a week ended without being closed | the week's honest truth, next week's single win, and one system experiment with a test |
| [`late-promise.md`](late-promise.md) | a promise in the ledger will be missed, detected on or before its notice-by date | a renegotiated date agreed before the deadline, or a recorded decision to accept the consequence |
