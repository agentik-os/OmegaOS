# Wealth & Capital OS, v1.0.0

**Category:** Personal Stack / Personal Finance  
**Omega position:** Personal Stack: personal cash-flow, resilience, investment policy and capital allocation  
**Primary interface:** conversational + structured records  
**Status:** installable reference implementation

## Purpose
Give the user one conversational financial brain for personal cash flow, savings, emergency resilience, debt, goals, investment policy, risk and life-aligned capital allocation.

## Promise
Convert accounts, transactions, documents and goals into a trustworthy personal financial picture, timely reminders and disciplined decisions.

## Core equation

```text
FINANCIAL FREEDOM = CLARITY × MARGIN × RESILIENCE × COMPOUNDING × RISK DISCIPLINE × LIFE ALIGNMENT
```

## Operating loop

```text
INGEST → VERIFY → CLASSIFY → CLOSE → DIAGNOSE → PLAN → ACT WITH APPROVAL → RECONCILE → REVIEW
```

## What this OS contains
- Canonical system prompt and explicit boundaries
- 12 specialist agents
- 20 reusable skills
- 7 operating protocols
- domain memory and privacy model
- JSON schemas for 7 core entities
- evaluation suite and adversarial tests
- provider-neutral reference runtime
- curated book canon and source ledger

## Commands
| Command | Mode | Purpose |
| --- | --- | --- |
| `/wealth` | dashboard | Open personal CFO dashboard |
| `/money-close` | close | Reconcile the month |
| `/cashflow` | dashboard | Analyze personal cash flow |
| `/saving` | plan | Create or revise savings plan |
| `/emergency-fund` | plan | Size and fund resilience reserve |
| `/debt` | decision | Choose a debt strategy |
| `/invest-policy` | plan | Create an investment policy statement |
| `/purchase` | decision | Evaluate a major purchase |
| `/money-scenario` | scenario | Model a financial scenario |
| `/receipt` | ingest | Stage a personal document or receipt |

## Main handoffs
- Revenue OS sends only `revenue.owner_distribution.verified` (verified owner pay/distribution); raw business reserve or transaction history never crosses this boundary.
- Strategy & Portfolio OS receives personal capital constraints, not raw transaction history.
- Execution OS receives agreed money tasks and reminders.
- Qualified advisers receive organized records and question packs.
