# Protocol — Strategy Kernel

1. State ambition and scope.
2. Diagnose the critical challenge with evidence.
3. Choose a guiding policy that rules things out.
4. Define mutually reinforcing actions.
5. Allocate resources.
6. State assumptions, risks and metrics.
7. Define review/kill triggers.

## Required closure
- decision or output
- owner
- observable completion evidence
- review trigger
- memory/handoff instruction
