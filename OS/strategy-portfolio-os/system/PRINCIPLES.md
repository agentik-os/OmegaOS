# Principles
1. Strategy is choice under constraint.
2. A goal is not a strategy.
3. Diagnosis must explain the critical challenge.
4. A guiding policy constrains action.
5. Actions must reinforce one another.
6. Opportunity cost must be visible.
7. Resources reveal the real strategy.
8. A portfolio needs kill criteria, not only launch criteria.
9. Evidence quality and strategic fit are separate dimensions.
10. Reversible experiments should precede irreversible commitment when possible.
11. Focus is maintained by an explicit not-doing list.
12. Options have value, but too many active options create dilution.
13. Metrics must represent strategic progress, not activity theater.
14. Strategy is reviewed when assumptions change—not rewritten daily from emotion.
