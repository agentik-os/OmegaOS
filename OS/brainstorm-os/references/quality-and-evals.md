## 1. Evaluation philosophy

Evaluate the observable quality of artifacts and decisions, never private chain-of-thought. A polished answer can still fail if directions are cosmetic, dissent is performative, evidence is fabricated, or the recommendation cannot be falsified.

Scores support judgment. They do not authorize convergence by themselves.

## 2. Core scorecard

Score each dimension 0–4 and attach one evidence sentence.

| Dimension | 0 | 2 | 4 |
| --- | --- | --- | --- |
| Intent fidelity | Founder intent lost | Partially preserved | Transformation, constraints, and non-goals explicit |
| Direction diversity | One idea reworded | Some mechanism variation | Orthogonal mechanisms and an inversion |
| Dissent quality | Agreement theatre | Objections but weak causality | Steelmanned, causal, falsifiable opposition |
| Evidence hygiene | Facts invented | Labels inconsistent | Facts/inference/hypotheses and provenance cleanly separated |
| Tension integrity | Tradeoffs hidden | Named but averaged | Poles preserved and explicitly resolved/accepted/deferred |
| Recombination quality | Feature bundle | Compromise | New coherent mechanism created from compatible strengths |
| Decision clarity | Generic options | Preference implied | Recommendation, alternative, rejection reasons, revisit trigger |
| Falsifiability | No disconfirmers | Generic tests | Decisive evidence, thresholds, and kill criteria |
| Feasibility realism | Magic execution | Major dependencies noted | Recurring operations, bottlenecks, and scale effects visible |
| Consequence depth | First-order only | Some risks | Incentives, abuse, second-order and anti-goal analyzed |
| Traceability | No IDs/links | Partial mapping | Sources → hypotheses → arguments → decisions → experiments |
| Handoff readiness | Transcript dump | Useful summary | Downstream contract complete and scope-pure |
| Frame originality | Original solution is premise | Some reframing | Several structurally different frames reveal new mechanisms |
| Evolutionary depth | Cosmetic variants | One structural mutation | Multi-locus mutations, crossovers, generations, parentage, selection pressure |
| Valuable surprise | Familiar default or randomness | Novel but weakly causal | Non-obvious, coherent, intent-faithful direction changes the decision |
| Surface fitness | Platform chosen by habit | Affordances noted | User moment, native advantage, burden, alternative, and prototype are explicit |
| Portfolio coherence | Idea sprawl | Claimed synergy | Shared primitives, conflicts, boundaries, sequencing, and distraction risk are explicit |

Recommended gates:

- `SPARK`: no minimum; display that it is exploratory.
- `COUNCIL`: average ≥2.5, with no zero in dissent, evidence, or decision clarity.
- `DEEP`: average ≥3.2, with dissent, evidence, falsifiability, and traceability each ≥3.
- `CONVERGED`: no critical unresolved conflict; all mandatory dimensions ≥3.

## 3. Anti-consensus tests

### Independence test

Can each cell's first position be traced to an independent brief before seeing other conclusions? If not, mark contamination.

### Non-cosmetic diversity test

Remove names and presentation. Do directions still differ in actor, job, causal mechanism, value unit, trust, economics, distribution, ownership, or time horizon? If not, reopen divergence.

### Minority survival test

Does the final output retain the strongest plausible dissent and its revisit trigger? If not, synthesis likely laundered consensus.

### Familiarity-bias test

Did a conventional mobile/web/SaaS default beat a stranger coherent concept only because it was easier to explain or score? If yes, rerun valuable-surprise and causal-chain evaluation before selection.

### Genetic-diversity test

Can mutations be traced to changes in at least two idea-genome loci and immutable parent IDs? If not, idea volume is cosmetic.

### Surface-independence test

Does the concept still make sense before a platform is named, and does the selected surface improve the causal value mechanism through a native affordance? If not, the interface has replaced the idea.

### Primary-value-event test

Does the primary surface own the highest-leverage value event rather than merely the most frequent capture or notification moment? If not, relabel the companion and primary surfaces before handoff.

### Multi-surface role test

Does each selected surface own a non-redundant moment, with canonical state, degraded mode, release sequence, and scope firewall? If not, reject multi-surface or reduce to one primary surface.

### Self-revision test

Did at least one cell or the Chair change a material position because of an opposing argument or evidence? If nobody revised anything, investigate debate theatre.

### Crux test

Can the Council state the proposition that actually separates competing views and the evidence/value choice that resolves it? If not, disagreement remains rhetorical.

## 4. Concept quality tests

- **Causal chain:** actor action → mechanism → value event → durable consequence.
- **Substitution:** why the actor changes from status quo, non-consumption, manual workaround, or adjacent solution.
- **10× test:** what breaks at 10× users, cost, latency, regulation, or social exposure.
- **10% test:** what survives with 10% of budget, features, data, or time.
- **Anti-goal test:** how success metrics could violate the mission.
- **Founder-edge test:** what non-commodity advantage or conviction makes this worth pursuing.
- **Dependency test:** what must already be true outside the founder's control.
- **Narrative integrity:** whether the promise can remain true as the system monetizes and scales.
- **Valuable-surprise test:** whether novelty remains useful after the name, aesthetic, and technology are removed.
- **Genome distance:** whether serious concepts differ across at least two loci.
- **Surface thesis:** whether native affordance at a specific moment causally improves the value event enough to justify burden.

## 5. Council process tests

Record these observable measures:

- number of materially distinct mechanisms;
- number of independent cells and specialist mandates;
- number of strong objections mapped to a target idea;
- number of positions revised after cross-examination;
- share of critical hypotheses with falsifiers;
- share of locked/provisional decisions with rationale and revisit trigger;
- unresolved critical tensions;
- challenge rounds with a material delta;
- rejected ideas with explicit reasons;
- evidence-dependent claims without an owner.
- alternate frames with meaningful structural distance;
- evolutionary generations and multi-locus mutations;
- selected surface with role map and next-surface trigger where applicable;
- incubated concepts with non-calendar resurrection triggers.

Warn on:

- more than 12 directions without clustering;
- more than 5 challenge rounds without new evidence or a material delta;
- convergence where every cell recommends the original idea unchanged;
- scores with no evidence sentence;
- experiments whose thresholds cannot change a decision;
- handoffs containing downstream specifications not owned by Brainstorm {OS}.
- multi-surface selection with duplicated feature roles or no canonical state owner;
- `IMAGINATION` or `DEEP` convergence with no recorded frame fission or evolutionary generation;
- novelty scores that reward randomness, technology fashion, or naming alone.

## 6. Handoff gates

### Research-ready

- research questions map to risky hypotheses;
- market/category boundaries are hypotheses, not facts;
- evidence already gathered has provenance;
- thresholds define how decisions will change.

### Blueprint-ready

- one selected concept and one strongest alternative;
- founder intent, users/JTBD hypotheses, mechanism, value, principles, constraints, and non-goals are explicit;
- decisions and open unknowns are classified;
- project boundary prevents leakage;
- no complete screen/API/architecture specification is smuggled in.

### Decision-brief-ready

- decision, criteria, options, evidence, sensitivity, dissent, risk, reversibility, and revisit trigger are present.

## 7. Recovery actions

| Failure | Required recovery |
| --- | --- |
| Low diversity | Change two structural axes; use inversion or morphological matrix |
| Weak dissent | Assign Adversarial Cell a precise causal failure claim and kill criteria |
| Evidence contamination | Relabel unsupported claims; route material facts to research |
| Vague tension | State both valuable poles and the cost of optimizing each |
| False synthesis | Split the concept; preserve competing models until crux is resolved |
| Infinite challenge | Require new evidence, new lens, or converge/park |
| Weak experiment | Define signal, threshold, confound, and exact next decision |
| Unclear recommendation | Force Chair to select, state confidence, and retain one alternative |
| Scope leakage | Remove downstream artifacts and emit the correct handoff contract |
