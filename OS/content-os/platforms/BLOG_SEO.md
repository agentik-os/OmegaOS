# Blog & SEO Playbook

Start with search/user intent, not a keyword list. Build the page that fully resolves the question through clear structure, firsthand evidence, primary sources, examples and useful tools. Map topic clusters and internal links, maintain dates and update stale claims.

**Brief:** query/intent; audience sophistication; competing alternatives; unique angle; outline; sources; examples; visuals/data; internal links; CTA; snippet/schema opportunities; update trigger.

**Avoid:** keyword stuffing, derivative summaries, invented expertise, pages made only for search engines, stale statistics and unsupported AI-generated claims.
